# 本地画廊标签数据库

下载设置 → 本地标签数据库。默认自动补全下载列表内全部画廊；关闭后可手动补全。
下载列表菜单 → 本地标签筛选，输入 `other:extraneous ads` 或任意原始标签；空输入取消筛选，“标签未知”显示未取得完整快照的画廊。

## 实现决策

- 独立 Room 库 `eh_tags.db`，不改变原有主库，不加入应用导出，并排除 Android 自动备份和设备迁移。
- 两张表：完整标签快照关联表和持久化同步状态表。保留命名空间，索引支持精确标签查询。
- 复用现有 HTTP 客户端、认证和站点设置，使用 gdata，每批至多 25 个、间隔 5 秒。失效条目独立处理。
- WorkManager 约束联网、指数退避、串行队列。暂停在当前请求结束后生效；重启可续跑。大任务分段执行。
- 重新获取全部标签保留旧快照直至成功；不可用画廊跳过，可显式重试。网络和身份异常不标记为永久失效。
- 新增、导入下载后及应用启动时自动补齐。优先使用下载记录 token，缺少时读取本地 .ehviewer；仍缺少就跳过。
- 本阶段只建设标签索引，不删除广告图片。标签标记不证明具体广告页位置。
- 调试包增加 ARM64，便于安卓真机验证；调试应用 ID 带 .debug，可与正式版共存。

## 验证

执行 `./gradlew spotlessCheck testDebugUnitTest assembleDebug`。
单测覆盖混合批次、失效/认证/缺失响应、空标签、命名空间和重复标签；数据库测试覆盖刷新保留、替换旧标签、空快照、不可用跳过及 token 修复。

真机验证：已有下载 → 补全 → 观察计数 → 广告标签筛选；断网恢复、暂停继续、杀进程后续跑；导入旧备份后补齐；原有导出仍可由原版读取。
由于云环境没有用户 EH 登录会话和真实下载列表，网络端到端和真机交互需在设备中验证。
