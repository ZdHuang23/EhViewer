# 广告页排除与空间统计

## 使用方式

在「设置 → 下载 → 广告页清理」中：

- **清理已有下载／继续清理**：处理本地标签数据库中带有 `other:extraneous ads` 的已完成下载。先补全标签能覆盖更多画廊；未知标签和未完成下载不推断为广告。
- **下载完成后自动清理广告页**：默认关闭。开启后，只将随后完成下载的画廊加入持久待处理队列，不自动清理整个历史下载库。新下载的标签尚未同步时保留待处理项，标签同步完成后继续；即使关闭了常规标签自动同步，此功能仍会为新下载请求标签同步。标签同步暂停开关仍然生效。
- **暂停广告清理**：在当前画廊处理完后暂停。关闭暂停或点击继续可恢复批量任务。退出应用不会丢失已保存的页级处理结果。
- **广告清理状态**：显示画廊进度、本轮移除图片的页数、失败数、未检查／删除失败数、等待标签数。重复扫描没有再次删除图片时，不重复计入空间清理成果。

自动／批量流程只检查候选画廊的**最后 7 页**，用离线 ZXing QR 解码器判断是否存在二维码。不请求二维码链接，不上传图片。二维码不一定是广告，识别范围是一项启发式规则，并非内容审核。

阅读器内长按页面：

- **将此页标记为广告并删除图片**：不要求有广告标签，也不限页码。
- **标记整本已去广告**：记录手动处理完成，停止以后的自动二维码检查；已有页级广告记录仍然生效。若通过文件管理器手动删除了图片，仍需逐页标记，整本完成标记不擅自把所有缺页当成广告。
- **重新检查最后 7 页二维码**：重置尾页检查进度与手动完成状态，检查现有下载图片，不额外请求图片，也不要求有广告标签。手动恢复过的页面仍然受保护。
- **刷新**广告占位页：确认后撤销该页广告标记、重新下载，并将它列为自动识别的例外。再次手动标记该页为广告可撤销该例外。点击占位文字只打开操作菜单，不直接恢复下载。

页菜单同时显示已标记的广告页数、尾页检查进度和手动处理完成状态。

## 删除与下载完整性

保留原始总页数、页码与排序。广告页显示“此页已被标记为广告，图片已删除”，不折叠或重排页面。

页级标记先写入独立持久记录，再写入下载目录副本，成功后才删除该页下载文件及阅读图片缓存。删除失败保留标记，可重试。识别失败或缺失图片不记录为“无二维码”，留待下次检查。

SpiderQueen 的网络获取入口在获取 pToken / 请求网络前检查广告标记；SpiderDen 将其视为无需补全的页面，并拒绝读取、解码及导出标记页。广告页计入完成页数，因此继续下载、重试和全部下载不会把广告当成缺页。只有阅读器的显式强制刷新会恢复页面。

识别、手动标记、下载与解码共用页锁，防止删除后仍有在途任务将图片写回。读者缓存会在标记后失效，切换为占位。批量任务持久保存画廊检查点；页内中断依靠已保存的 `checked` / `ads` 继续。

## 数据兼容性与备份

- 不修改 `eh.db`、`.ehviewer` 原有字段和图片命名规则。
- 广告决策主记录：应用私有 `files/ad-pages/<gid>.json`，使用 Android `AtomicFile` 写入；与可重建的 `eh_tags.db` 分离，不随重建标签库清空。
- 下载目录副本：每本画廊的 `.ehviewer-ads.json`。迁移下载目录时保留此隐藏文件。私有记录丢失后可从副本恢复。
- 记录包含版本、gid、token、原始页数、广告页、恢复例外、已检查页及手动完成状态。token 或页数变化时不应用旧页索引，避免误删不同版本的内容。
- 私有广告记录纳入系统备份。原有手动导出的 `.db` 格式保持不变，因此它本身不包含广告记录；备份画廊目录时应保留上述副本。
- 记录损坏且无法安全读取时停止准备／清理该画廊，不默默清空标记后重新下载。
- 原版应用不认识新增记录，可能补回这些图片；下载跳过保障针对本分支应用。目录和原版元数据格式保持兼容。

## 只读空间占用

「设置 → 下载 → 下载缓存空间占用」分别显示：

1. 当前下载目录全部文件的实际大小（递归统计，包含元数据和目录内其他文件）。
2. 阅读图片磁盘缓存的实际占用，不是配置的缓存上限，不包括缩略图和 HTTP 缓存。

统计不修改或清理文件。进入设置页及后台清理完成后重新统计；无法读取的项目注明统计不完整。数字是统计时的快照，下载同时进行时会变化。

## 验证范围

自动化测试覆盖二维码（普通、反色、整页小二维码、空白与损坏图片）、记录持久化与目录恢复、身份隔离、先记录后删除、写入失败、取消和继续、恢复例外、重复清理统计、下载／读取／导出拦截、自动队列与批量检查点，以及空间统计随删除减少。

当前云环境没有 Android 模拟器或真机，未进行设备上的阅读器、SAF 文档提供程序及真实 EH 登录端到端验证。Robolectric、原生图形解码测试、APK 构建与签名校验用于本次自动验证。
